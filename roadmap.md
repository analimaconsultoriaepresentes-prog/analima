# Gestão de produtos e estoque — melhorias

## Valor único e etiquetas
- [x] Preço independente persistido e cadastro/edição com validação compatível.
- [x] Modelos por preços válidos e seleção múltipla com aviso de incompatibilidade.
- [x] Prévia, PDF e documento de impressão consistentes, preservando 47 × 23 mm e 48 por A4 (impressão em papel depende da impressora).
- [x] Testes de regras e verificação de cadastro, edição e etiquetas no navegador; cadastros de teste removidos.

- [x] 1. Detecção de produtos duplicados no cadastro (aviso com opções: editar existente, cancelar, confirmar)
- [x] 2. Código único por produto + busca por nome/marca/código + campo código de barras (opcional)
- [x] 3. Histórico de movimentação de estoque por produto (cadastro, entrada, venda, doação, devolução, ajuste) com saldo anterior/posterior
- [x] 4. Tela "Conferir estoque" (contagem física, diferença, ajuste individual/em lote com motivo)
- [x] 5. Filtros na tela Produtos (zerado, baixo, duplicados, sem movimentação, vendidos recentemente, inativos) + última movimentação + ordenação
- [x] 6. Ferramenta de revisão de duplicados (comparar cadastros; sem exclusão automática)
- [x] 7. Testes (duplicados, movimentações, conferência) + verificação no navegador
