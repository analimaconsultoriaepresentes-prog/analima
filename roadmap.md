# Gestão de produtos e estoque — melhorias

- [ ] 1. Detecção de produtos duplicados no cadastro (aviso com opções: editar existente, cancelar, confirmar)
- [ ] 2. Código único por produto + busca por nome/marca/código + campo código de barras (opcional)
- [ ] 3. Histórico de movimentação de estoque por produto (cadastro, entrada, venda, doação, devolução, ajuste) com saldo anterior/posterior
- [ ] 4. Tela "Conferir estoque" (contagem física, diferença, ajuste individual/em lote com motivo)
- [ ] 5. Filtros na tela Produtos (zerado, baixo, duplicados, sem movimentação, vendidos recentemente, inativos) + última movimentação + ordenação
- [ ] 6. Ferramenta de revisão de duplicados (comparar cadastros; sem exclusão automática)
- [ ] 7. Testes (duplicados, movimentações, conferência) + verificação no navegador
